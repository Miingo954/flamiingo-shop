# FLAMIINGO Shop

A responsive fashion storefront concept for the FLAMIINGO brand.

## Features

- Video hero section
- Responsive brand navigation
- Shop and preorder calls to action
- Interactive search, menu, and bag controls
- Mobile-friendly layout

## Built With

- HTML
- CSS
- JavaScript

## Requirements

No Node.js installation is required.

## Run Locally

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/Miingo954/flamiingo-shop.git
cd flamiingo-shop
open index.html
```
